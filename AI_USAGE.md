# AI usage

AI assistance was used in the Wow round to implement the mission-control redesign, the Decision Pipeline, the dashboard, the auto-demo, the PWA assets, the printable handover, the safety/limits/prompt pages and the documentation updates. The same working session also ran the syntax checks, test suites, evaluation, headless-browser checks and screenshot capture.

No runtime AI service or external model API is connected. Runtime triage is performed by the deterministic phrase rules in `rules.json` and `classifier.js`. The app does not send entered text to a model provider, and it does not learn from the local history. Browser speech synthesis is used only for the optional read-aloud button, after a user gesture; browser speech recognition is optional, feature-detected and opt-in.

The synthetic expected labels are stored separately from their messages. Evaluation results are generated by the local evaluation script and describe fixture agreement only. They do not establish clinical performance or safety.

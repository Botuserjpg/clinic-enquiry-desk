# Prompts used

The project was built from the user-provided brief. The central implementation prompt was to create a small Australian GP front-desk enquiry tool using synthetic data, explainable triage, immediate 000 escalation for emergency wording, staff-approved reply drafts, an append-only history and a small dashboard. Safety constraints were to avoid diagnosis or medical advice, use no real patient data, and retain human approval.

An upgrade prompt requested a shared `rules.json`, browser and Python parity, local static mode, synthetic fixtures with separate labels, Python utilities, documentation and submission materials. It also required continued Node standard-library operation and factual logs.
